# Workflow notes

The point of this project is practising AI-assisted development, so this file
matters as much as the game. Fill in one entry per slice, right after
committing, while it's fresh.

Every third slice, read back through these and promote anything recurring into
the "Recurring mistakes" section of `CLAUDE.md`. That promotion step is the
whole loop — notes you never act on are just a diary.

## Deliberate experiments

Tick these off across the project. They fail in different ways and you want to
see all of them.

- [ ] A greenfield feature slice
- [ ] A refactor of code that already works
- [ ] A bug hunt starting from a stack trace only
- [ ] An ambiguous "make this feel better" task
- [ ] Integrating an external asset or addon
- [ ] **One slice with no AI at all**, as a control — the only way to know
      whether the workflow is actually faster or just feels faster
- [ ] Deliberately reject a plan as too clever and ask for a simpler one
- [ ] Around slice 7, ask for a full walkthrough of the codebase and count how
      much you can't explain
